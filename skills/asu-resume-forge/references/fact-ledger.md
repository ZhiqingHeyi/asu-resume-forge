# 事实账本（Fact Ledger）模板

> F1 工序产出物。只登记事实，不登记修辞。任何无法确认的信息进「待确认」。

## 基本信息

- 姓名 / 联系方式 / 城市：
- 学校 / 专业 / 学位 / 起止时间 / Title 核验来源（学校官网等）：
- 当前身份（在职 / 应届 /  gap）：

## 经历条目（每段一行账）

| 字段 | 内容 | 证据 |
|---|---|---|
| 组织 | 公司/团队全称 | |
| 角色 | 真实角色（L1-L4 哪一级） | |
| 时间 | 起止 | |
| 背景 | 为什么做（一句话） | |
| 个人边界 | 你具体负责哪一段 | |
| 难点 | 真正难的地方 | |
| 动作 | 关键设计/实现 | |
| 原始数字 | 未经加工的原始量（如 4h、30min、3000 条/日） | 来源（日志/看板/评测集） |
| 派生数字 | 由原始数字算出的指标（需过 metric-check） | 计算过程 |
| 可验证物 | 链接 / 截图 / 演示地址 | |
| 归属关系 | 该作品与哪个平台/项目的关系（避免作品-项目对不上） | |

## 待确认清单

| # | 待确认项 | 影响哪句话 | 状态 |
|---|---|---|---|
| 1 | 例：最大导出行数 | "支撑 50 万行导出" | 待补 |

规则：待确认项清零前，相关句子不得出现在成稿里（或以"待确认"标注留在草稿中）。
