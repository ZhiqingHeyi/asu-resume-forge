# 句式库（Phrasebook）

## 三段式段首

- **背景与痛点**："……依赖人工，效率低、易出错，存在 xx 风险。"
- **背景与目标**："公司缺乏 xx，各团队重复建设；目标是从 0 到 1 搭建 xx。"
- **指标与效果**："xx 时间从 A 缩短至 B（提效约 N%），综合成本约为原来的 1/M；
  已在 N 个场景常态化使用。"
- **我的职责**："项目 Owner，完全负责从 0 到 1 设计并落地：……"

## 角色强度句式（按真实级别选用，不得越级）

- L4："项目 Owner，完全负责从 0 到 1 设计并落地以下系统与技术链路"
- L4 独立："独立负责需求定义、交互设计、全栈开发、部署与运营全流程"
- L3："主导 xx 模块的方案设计与落地，负责 xx 决策"
- L2："负责 xx 模块的开发与交付，实现 xx"
- L1："参与 xx，承担 xx 部分"

## 难点 → 解法 → 收益

- "难点：……（真正的技术/业务难点，一句话）"
- "解法：设计 / 首创 / 引入 ……，通过 …… 机制解决"
- "收益：……（量化，含口径）"

## 链路行

- `↳ 技术链路：A → B → C → D`（全栈）
- `↳ 产品链路：A → B → C → D`（产品）
- `↳ 架构链路：A → B → C → D`（架构）
- `↳ 交付链路：调研 → 勘察 → 部署 → 打通 → 培训 → 复盘`（FDE）

规则：4~8 环；每环是一个可追问的组件/动作；讲不清的环不上链。

## 持续价值句式

- "定时任务持续运行，形成'复购式'使用"
- "累计使用 N 次，为平台 Top1 高频应用（全集：N 个智能体）"
- "已在 N 个大型工程 / 部门常态化使用"
- "上线至今零安全事故，数据不出内网"

## 架构取舍句式

- "架构取舍：优先复用 X 成熟底座而非自研，换取 N 个月上线窗口；
  xx 按业务域分类，牺牲部分灵活性，换取使用方零学习成本。"

## 抓手埋点句式

- 能力矩阵："大模型 API 接入与大小模型分层路由（推理成本降 N%）、Function Calling
  与工具调用链路、上下文工程（写入/选择/压缩/隔离）"
- 项目内："技能不可用时自动回退通用对话，保障服务可用性"

## 教育背景（一句话带过，不占黄金位置）

- "xx 大学 · 计算机科学与技术（工学学士）　2021.09 – 2025.06　[211/双一流]"
- 细节只留一句："科班基础扎实，具备独立完成 xx 的能力。"
